# Levi's Quotes Department

A vintage archive-themed quote search application built with HTML, CSS, and JavaScript using the DummyJSON Quotes API.

## Overview

Levi's Quotes Department is a quote discovery website inspired by old paper archives and filing systems. Users can search for quotes, browse categorized mood codes, and copy quote cards for sharing.

The application retrieves quote data from the DummyJSON API and organizes results into custom mood categories inspired by themes such as love, courage, hope, sadness, and personal growth.

## Features

* Search quotes by keyword
* Browse quotes using Mood Codes
* Dynamic quote classification
* Copy quote cards to clipboard
* Responsive vintage newspaper-inspired interface
* Powered by the DummyJSON Quotes API
* No backend required

## How It Works

1. The application loads quote data from the DummyJSON API.
2. Users enter keywords or select a Mood Code.
3. Quotes are filtered and categorized.
4. Matching quotes are displayed as archive cards.
5. Users can copy any quote card to their clipboard.
